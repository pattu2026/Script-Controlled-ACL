# Project Documentation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Description
This project demonstrates how to implement script-controlled Access Control Lists (ACLs) in ServiceNow to restrict record access based on user roles and the Branch field.

## Roles Used
- bb1 – Read access
- bb2 – Create access
- bb3 – Write access
- bb4 – Delete access
- Admin – Full access

## Table
- Label: Institution Details
- Name: u_institution_details

## Branch Values
- ECE
- EEE
- CSE

## Outcome
The project demonstrates record-level security using READ, CREATE, WRITE and DELETE ACLs.
