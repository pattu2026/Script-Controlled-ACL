# Project Development

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Development Steps

1. Create the EEE User.
2. Create roles bb1, bb2, bb3 and bb4.
3. Create the Institution Details table.
4. Add records with different Branch values.
5. Create the READ ACL using role bb1 and Branch = EEE.
6. Create the CREATE ACL using role bb2.
7. Create the WRITE ACL using role bb3.
8. Create the DELETE ACL using role bb4.
9. Test the ACLs using different users.
10. Verify administrator access.
